# YTM_Immersion

YTM_Immersion は、YouTube Music の Web 版を Apple Music 風の歌詞プレイヤー表示へ変更する Chrome 拡張機能です。

## 特徴

- **リアルタイム歌詞同期**：LRCHub と連携し、再生位置に合わせて歌詞を追従表示します。
- **半透明 UI**：プレイヤーバーとナビゲーションバーの表示を、半透明のデザインへ統一します。
- **通常表示への切り替え**：Immersion モードをオフにすると、キューの確認や検索を行えます。
- **歌詞翻訳**：DeepL API を設定すると、歌詞を翻訳できます。
- **LRC 読み込み**：LRC ファイルを読み込み、オンラインで歌詞を取得できない曲にも歌詞を表示できます。

## インストール

この拡張機能は、Chrome ウェブストアからではなく、開発者モードで手動インストールします。

### 1. ファイルの準備

1. 最新の `.zip` ファイルをダウンロードします。
2. ZIP を展開し、生成されたフォルダをそのまま使用します。

### 2. Chrome への読み込み

1. Chromium 系ブラウザを開きます。
2. アドレスバーで `chrome://extensions` を開きます。
3. 画面右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックします。
5. 手順 1 で展開したフォルダを選択します。

### 3. 使い方

1. YouTube Music を開き、曲を再生します。
2. 画面右下のコントロールバーにある `[IMMERSION]` ボタンをクリックすると、Immersion モードのオンとオフを切り替えられます。

## 対応環境

Chromium をエンジンとするブラウザを対象としています。
macOS / Windows / Linux での利用を想定していますが、主に macOS 上で開発しているため、Windows では UI の表示差が生じる可能性があります。
